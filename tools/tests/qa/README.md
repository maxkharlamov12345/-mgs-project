# Дотошный обход сайта (видео + вёрстка)

Дольше и тяжелее, чем `tools/tests/check.py`; запускать после крупных изменений в видео, просмотре или лентах.

    sh tools/tests/qa/make_vp9.sh                   # один раз / после новых видео
    python3 tools/tests/qa/qa_server.py 8799 &      # сервер «как GitHub Pages»: Range, кэш 10 мин, видео — VP9-копии
    python3 tools/tests/qa/qa_full.py i13 lap       # устройства: se i13 ipad lap fhd (без аргументов — все, ~40 мин)

Что ищет: чёрные кадры на видео (снимает экран на каждой перерисовке), прыжки вёрстки (layout shift),
горизонтальную прокрутку, битые картинки, обрезанный текст, «играет больше одного видео».
Сценарии: старт портфолио, смена всех лент, REELS на телефоне (касания, 1/2 в ряд), Комплекс → проект → назад,
страницы проектов (лента, просмотр, рилсы), просмотр в портфолио, всё то же на медленном интернете.
Снимки контрольных точек и кадры с найденными чёрными плитками (BLACK_*, красная рамка) — в `tools/tests/qa/qa_shots/`.
Известные ложные срабатывания: самый первый кадр загрузки страницы, тёмный фон по краям окна рилсов на ПК.
